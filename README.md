# Web curs anterior VOID BCN

Aquest projecte correspon al lloc web desenvolupat durant el curs anterior per a la marca i serveis de Maria Oliver. Es tracta d'una aplicació web multi-pàgina dissenyada per oferir informació sobre els serveis, galeria de treballs, secció de contacte, registre d'usuaris i informació legal/FAQ.

# Descripció i Tecnologies Utilitzades

 La web ha estat estructurada de forma modular i adaptativa per tal de garantir una experiència d'usuari fluida en diferents dispositius.

# Tecnologies utilitzades:

 HTML5: Estructuració semàntica de les diferents seccions de la web (index.html, galeria.html, contacte.html, registre.html, FAQ.html, etc.).

 CSS3: Disseny, maquetació i estils visuals utilitzant el fitxer centralitzat styles.css.

 JavaScript: Validació de formularis i interactivitat dinàmica a través del fitxer javascript.js.

 Firebase Hosting: Servei d'allotjament al núvol utilitzat per al desplegament en línia de la web.

# Indicacions per obrir-la o executar-la localment

Pots executar i visualitzar aquest projecte en el teu entorn local de dues maneres diferents:

  1. Directament des del navegador
  
  * Descarrega o clona aquest repositori a la teva màquina.
  * Navega fins a la carpeta arrel del projecte. 
  * Fes doble clic sobre el fitxer index.html (o fes clic dret > Obrir amb el teu navegador preferit).

  2. Mitjançant un servidor local 

  * Obre la carpeta del projecte amb l'editor de codi Visual Studio Code.
  * Instal·la l'extensió Live Server (si no la tens instal·lada).
  * Fes clic dret sobre el fitxer index.html i selecciona "Open with Live Server".
  
  La web s'obrirà automàticament a l'adreça  http://127.0.0.1:8080
